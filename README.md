# 灵感脑袋微信小程序

「灵感脑袋」是一个微信原生小程序，用来保存语录、图片灵感和自定义标签。当前版本使用微信云开发保存数据，不需要用户注册账号；小程序会通过微信 `openid` 自动区分不同用户。

## 数据保存方式

- 云数据库集合 `inspirations`：保存文案、图片 fileID、状态和自定义标签设置。
- 云存储目录 `users/{openid}/inspirations/`：保存用户上传的原图和缩略图。
- 本地 Storage：保留当前用户最近一次云端数据，断网或云同步失败时用于展示缓存。
- 旧版本本地数据：用户第一次进入首页时自动迁移到云端，迁移成功后清除旧缓存。

## 同步策略

- 首页首次从云端加载 30 条，滚动到底后继续加载下一页。
- 已加载页面和分页游标保存在本地，冷启动会先显示缓存，再做云端增量同步。
- 搜索或切换标签时会自动补齐剩余分页，避免只搜索首屏数据。
- 每条灵感带有云端版本号；多设备修改不同字段时自动合并，修改同一内容时提示用户检查后再次保存。
- 自定义标签及被用户删除的默认标签会同步到云端，换设备后仍保持一致。
- 首页优先加载 360px 缩略图，详情和全屏预览仍使用原图；旧数据会在首页同步后分批补齐缩略图。
- 新增和编辑文案都会在云函数中执行文字安全检测，未通过时不会写入数据库。
- 删除或替换图片时先记录待清理文件，再尝试删除；失败任务由定时云函数继续重试。
- 删除记录会保留 30 天轻量同步标记，供其他设备同步删除状态，之后由定时任务移除。

## 首次部署

### 1. 开通云开发

1. 用微信开发者工具打开本项目。
2. 点击工具栏中的“云开发”。
3. 确认使用的环境 ID 是 `cloudbase-d5gi7lrk1ed819fe7`。
4. 如果换了云环境，同时修改 `app.js` 中 `wx.cloud.init` 的 `env`。

### 2. 创建数据库集合

1. 进入“云开发控制台 > 数据库”。
2. 新建集合，名称填写 `inspirations`。
3. 集合权限设置为“所有用户不可读写”，数据只允许通过云函数访问。

云函数拥有服务端权限，不受客户端“不可读写”限制。不要把集合设置成所有用户可读写。

### 3. 设置云存储权限

进入“云开发控制台 > 存储 > 权限设置”，选择“仅创建者可读写”或等价的按创建者隔离规则。图片由当前用户在客户端上传，删除由云函数完成，不要设置成所有用户可写。

### 4. 部署云函数

在开发者工具左侧找到 `cloudfunctions`，分别右键以下三个目录：

- `contentSecurityCheck`
- `inspirationData`
- `cleanupInspirationData`

三个目录都选择“上传并部署：云端安装依赖”。云函数代码有任何修改，都需要重新执行这一步。

本次升级不需要重新创建集合，也不需要手动添加字段。更新代码后必须重新部署 `inspirationData`，并首次部署 `cleanupInspirationData`；否则文字检测、标签同步和失败文件的定时清理不会完整生效。`cleanupInspirationData` 默认每天 03:00 执行。

数据量增大后，可以在 `inspirations` 集合中增加 `ownerOpenId + updatedAt` 组合索引来提升增量同步效率；没有该索引时云函数会自动使用兼容查询，不影响正常运行。

### 5. 真机验证

部署完成后先清除开发者工具缓存并重新编译，再用“预览”扫码测试：

1. 新增纯文案灵感。
2. 新增单图和多图灵感。
3. 编辑文案、替换图片和删除图片。
4. 置顶、标记用过和删除灵感。
5. 退出后重新进入，确认数据仍在。
6. 用另一台设备登录同一微信，确认数据可以恢复。
7. 有旧版本数据时，确认首页提示“旧数据已同步到云端”。迁移完成前不要主动清除手机上的小程序数据。
8. 两台设备同时打开同一条灵感，分别修改后保存，确认不会静默覆盖较新的内容。
9. 新增自定义标签后换设备打开新增页，确认标签可以恢复；删除标签后再次换设备，确认删除状态已同步。
10. 上传图片后确认首页显示正常，点击详情和全屏预览时仍能查看清晰原图。
11. 输入明显不合规的测试文案，确认页面提示未通过安全检测且不会保存。

## 发布新版本

1. 确认三支云函数已经部署到正式云环境。
2. 在微信开发者工具中点击“上传”，填写版本号和更新说明。
3. 登录微信公众平台，在“管理 > 版本管理 > 开发版本”中提交审核。
4. 审核通过后点击“发布”。

以后更新小程序代码不会清空云数据库或云存储。只有主动删除云环境、数据库集合或云文件才会影响用户数据。
